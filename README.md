# JEE Advanced 2028 Goal Tracker

Open `index.html` in a browser. The tracker includes the standard Physics, Chemistry and Mathematics chapter map; chapter completion, backlog items and weekly planning persist automatically in browser `localStorage`.

Use **Export backup** in Planner to save a portable JSON backup, and **Import backup** to restore it on another device. Each chapter is tracked through the intended workflow: theory, module, PYQs and Revision 1/2/3.
